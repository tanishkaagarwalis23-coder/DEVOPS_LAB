# Exercise 1: Kubernetes NGINX Deployment

## Objective
Deploy an NGINX application using Kubernetes and Minikube.

## Tools Used
- Docker
- Minikube
- Kubernetes
- kubectl
- NGINX

## Steps
1. Start the Minikube cluster.
2. Create a Kubernetes Deployment.
3. Expose the application using a NodePort Service.
4. Verify the application.
5. Access NGINX using a web browser.
